# 貪欲法

## 図でつかむ：早く終わる区間を選び、後続の余地を残す

半開区間[0,3),[1,2),[2,4)なら、終了が早い[1,2)を選ぶことで[2,4)も選べます。

```mermaid
flowchart LR
    A["候補の終了時刻で整列"] --> B["先に選ぶ<br/>1〜2"]
    B --> C["次に選ぶ<br/>2〜4"]
    C --> D["重ならない2区間<br/>境界2の一致は許可"]
```

## 概要・使いどころ

各時点で最も良さそうな選択を確定させる方法です。区間選択、締切順の処理、ソート後の割当などで使います。過去の選択をやり直さないので高速ですが、局所的な最良が全体の最良になることを証明する必要があります。

## 仕組み：区間選択と交換法

半開区間$[s,t)$を重ならないように最大個数選びます。長さは正、端点が一致する区間は両方選べるとします。終了時刻の早い順に並べ、直前の終了以降に始まる区間を選びます。

最適解の最初の区間を、全区間のうち最も早く終わる区間に交換しても、後続が使える時間は減りません。したがって、この区間を含む最適解が存在します。残りにも同じ議論を繰り返せるので最適です。開始時刻が早い順や長さが短い順では同じ証明はできません。

### 終了時刻順の区間選択

入力はN、N行の開始・終了時刻。選べる最大個数を出力。ソート$O(N\log N)$、走査$O(N)$、空間$O(N)$。

```python
import sys
input = sys.stdin.readline
n = int(input())
intervals = [tuple(map(int, input().split())) for _ in range(n)]
intervals.sort(key=lambda p: p[1])
last_end = None
answer = 0
for start, end in intervals:
    if last_end is None or start >= last_end:
        answer += 1
        last_end = end  # 最も早く空く選択を確定
print(answer)
```

入力例：

```text
4
0 3
1 2
2 4
3 5
```

出力例：

```text
2
```

## 注意点

「大きい順に選ぶ」だけで正しいとは限りません。硬貨1,3,4で合計6を作ると、大きい順は4+1+1の3枚ですが最適は3+3の2枚です。このような場合は[DP](03_dp.md)を検討します。区間に報酬が付いて合計報酬を最大化する問題も、上の個数最大化の貪欲法では解けません。

同値のときの扱い、閉区間か半開区間か、負の時刻の可能性を確認します。小さい全探索と比べると反例を探せますが、有限個のテストは証明の代わりにはなりません。[ソート](01_sorting.md)とセットで復習しましょう。

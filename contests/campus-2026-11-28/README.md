## 全体の振り返り

今回の課題は、実装以前の「問題文から解法を連想する」段階にあった。村人ごとの最大値、時間を進めるシミュレーションなど、まず思いついた表現にこだわると、本当に必要な対象を見失いやすい。

次回は、まず「何を最大化するか」「Kの単位は何か」「答えを出すのはいつか」を書く。小さい具体例で素直な処理を作ってから、毎回調べ直す必要がない部分を探す。仕事の問題では、DPに決める前に終了時刻順の交換を試す。

ヒントなしで解き直すときは、コードを閉じ、状態・並べ替えの基準・判定関数を先に言葉にする。その後、境界例を作り、最後に実装する。1週間後には別の入力で同じ説明ができるか確認する。

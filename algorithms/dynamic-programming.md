## フィボナッチ数列

状態は `dp[i] = i番目のフィボナッチ数`。初期条件は $F_0=0,F_1=1$、遷移は $F_i=F_{i-1}+F_{i-2}$ です。小さい添字から計算すれば、遷移元は既に確定しています。

以下では巨大整数の影響を抑えるため、値を $10^9+7$ で割った余りで保存します。時間 $O(N)$、空間 $O(N)$。直前2個だけを持てば空間 $O(1)$ にできます。

```python
n = int(input())  # n >= 0
mod = 10**9 + 7
dp = [0] * (n + 2)  # n=0でもdp[1]を用意できる
dp[1] = 1
for i in range(2, n + 1):
    dp[i] = (dp[i - 1] + dp[i - 2]) % mod
print(dp[n])
```

入力例：

```text
7
```

出力例：

```text
13
```

## 0/1ナップサックの基礎

各品物は高々1回使います。重さは正整数、価値は非負とします。

- 状態：$D_i[w]$ は「最初のi個から選び、重さの合計をw以下にした最大価値」。
- 初期条件：$D_0[w]=0$。何も選ばないことが可能です。
- 遷移：次の品物の重さa、価値bに対し、w<aなら使えません。それ以外は $D_{i+1}[w]=\max(D_i[w],D_i[w-a]+b)$。
- 答え：$D_N[W]$。

[既存ノートの実行可能なナップサック実装](../learning-notes/03_dp.md)は1次元に圧縮しています。容量を降順に更新することで同じ品物の再使用を防ぎます。時間 $O(NW)$、空間 $O(W)$。入力ビット数に対しては擬多項式時間で、Wが大きいと実行できません。

「重さがちょうどw」の状態なら未到達を負の無限大にする必要があり、上記の「w以下」と初期条件が異なります。配列の値の意味から初期化を決めましょう。
